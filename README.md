# ClaimdailyTH-landing-page
For lazy TH players to automatically sign in daily and redeem the latest codes rewards on the web.

**Live:** https://claimdailyth.biz.id

## what this?
This website is the promotional and information page for customers of
my daily check-in service. It is connected to a customer data
management dashboard that I use for daily data recapitulation,
validation, and operational reporting.

## Features
- Available in 11 languages with auto-detects the visitor's language, english fallback if unsupported
- Responsive design for mobile and desktop
- Interactive FAQ section
- Service information and registration guide
- Voluntary tip support via QRIS and USDC (Solana)
